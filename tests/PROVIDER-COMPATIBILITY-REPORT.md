## CLI Flags

- `--target <name>` filters report-only targets; repeat it for multiple targets or omit it for all targets.
- `--agent <metadata.name>` filters examples by declared agent name; repeat it for multiple agents.
- Positional paths restrict input ADL files.
- `--format json|summary` selects the deterministic JSON export or a human-readable summary.
- `--output <path>` writes the static report to a local file instead of stdout.
- `--list-targets` prints available report-only targets.
