# Local Executable Runtime Prototype Report

_Anchor issue: #224._

## Scope

This report covers the first bounded executable local ADL runtime prototype.

The prototype executes only repo-owned ADL examples through `scripts/run_local_agent.py`. It does not use a hosted provider, live MCP server, external network, credential lookup, payment rail, devnet, or mainnet.

## Evidence

The evidence suite is generated by:

```bash
/Users/loki/.pyenv/versions/3.14.3/bin/python3 scripts/local_runtime_prototype.py
```

The pinned fixture is `tests/fixtures/local-executable-runtime-prototype.json`.

Covered scenarios:

- `examples/simple-agent.yaml` dry-runs successfully and emits the expected local trace events.
- `examples/tool-agent.yaml --execute-tools` executes the deterministic `search_docs` fixture, passes source checks, and emits `tool.executed`, `source.checked`, and completion trace events.
- `examples/unsafe/unsupported-tool-fixture.yaml --execute-tools` fails closed with exit code `2` and denial guidance.
- `examples/unsafe/unapproved-source-fixture.yaml --execute-tools --allow-denied-tools` completes transport but fails required source gates.
- `examples/invalid/bad-runtime-target.yaml` fails schema validation before any runtime trace is emitted.

## Boundaries

The prototype evidence keeps these boundaries explicit:

- `localRuntimeExecutionAllowed=true`
- `deterministicLocalFixturesOnly=true`
- `networkAccess=false`
- `paymentAccess=false`
- `credentialAccess=false`
- `mcpInvocation=false`
- `mainnetAccess=false`
- `externalExecutionAllowed=false`

## Decision

The local runner is now a small executable prototype for simple/tool ADL examples, not only a compatibility report. The only execution path is deterministic local fixtures, with policy, denial, source-check, completion, and trace semantics preserved.
