# ADL Validation UI Prototype Report

_Issue: #158_

## Scope

`docs/adl-validation-ui.html` is a local/static prototype for reviewing ADL validation results while keeping ReddiAgent runtime behavior blocked.

## Evidence

- The page is generated by `scripts/adl_validation_ui.py`.
- Bundled examples are validated with the existing ADL JSON Schema and builder-facing guidance code.
- The page embeds the current simple, tool, payment, and invalid missing-instructions examples.
- Pasted ADL uses browser-only prototype checks for the core required fields and points users back to the authoritative local command.
- Focused validation: `python3 tests/test_adl_validation_ui.py`.

## Boundaries

- `runtimeExecutionAllowed=false`
- `networkAccess=false`
- `providerCalls=false`
- `mcpInvocation=false`
- `paymentAccess=false`
- `credentialAccess=false`
- `deploymentAllowed=false`

The prototype does not deploy anything, start a server, call providers, resolve MCP servers, touch wallets or payment rails, read credentials, or activate a live agent runtime.
