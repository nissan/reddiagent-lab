# ReddiAgent Research Taxonomy

_Created: 2026-05-21_

## Purpose

Use this taxonomy to compare agent frameworks, platform-native approaches, and homebrew/open-source systems without getting distracted by branding differences.

## Categories

### Frameworks

- LangChain / LangGraph
- LlamaIndex
- AWS Strands Agents
- CrewAI
- Microsoft AutoGen
- Microsoft Semantic Kernel
- Other serious contenders discovered during research

### Platform-Native Agent Construction

- OpenAI
- Anthropic / Claude
- Google Gemini
- AWS Bedrock
- Other hosted platforms with strong agent-building guidance

### Homebrew / Open Source / Emergent

- Ollama-based local agents
- OpenOnion
- OpenClaw
- Hermes Agent
- pi.dev
- solve.it / Answer.AI
- Regular Python with tool calling
- Other emergent tools worth tracking

## Comparison Dimensions

For each system, capture:

- Core philosophy.
- Agent definition primitive.
- Model abstraction model.
- Prompt/instruction model.
- Tool/function interface.
- Skill/reusable capability model.
- Memory and data-source model.
- Planning and execution loop.
- State and persistence model.
- Deployment/runtime model.
- Observability and debugging.
- Evaluation and guardrails.
- Multi-agent coordination.
- Auth/permissions/security model.
- Payment/reputation/economic hooks.
- Prosumer learning curve.
- Lock-in and portability risks.
- Best practices worth adopting.
- Anti-patterns to avoid.

## Output Template

Use one research note per system with these sections:

- Snapshot
- Construction Model
- Builder Experience
- ReddiAgent Implications
- Sources
