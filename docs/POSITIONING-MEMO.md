# Prosumer Positioning Memo

_Loop 80._

## Position

ReddiAgent should be the agent harness literacy layer for prosumers: a way to describe, validate, dry-run, and eventually deploy agents without starting from one vendor's mental model.

## Message

Build the agent once as model plus harness. Then choose whether it runs locally, on OpenAI, Claude, Gemini, LangGraph, OpenClaw, or another target.

## Differentiator

ReddiAgent makes the harness visible: tools, policies, data, memory, evals, traces, receipts, and payment/reputation extensions.
