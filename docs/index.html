Boundary contract

  • No mainnet access or production readiness claim.
  • No wallet, facilitator, payment rail, or settlement access.
  • No provider product call or live MCP invocation from this page.
  • No secret values are embedded in the public bundle.
  • Coolify deployment evidence must include health, rollback, and teardown metadata.
